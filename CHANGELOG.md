## [1.0.0] — 2025-01-01

### Added
- Anomaly detection engine with Z-score, IQR, and isolation-forest algorithms
- Streamlit dashboard for real-time business metric monitoring
- Alert pipeline with configurable severity thresholds
- Docker Compose deployment with Prometheus and Grafana monitoring
- Sample data generators for revenue, traffic, and conversion metrics
- GitHub Actions CI pipeline (lint → test → Docker build)
